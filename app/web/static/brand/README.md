# Brand assets

Two independent asset families, each kept as source + derivative for reproducibility.
Nothing in this directory is generated at runtime or referenced by an absolute
filesystem path; every derivative below was produced once, offline, and committed.

## Icon / favicon family (legacy checkpoint mark)

- `docguard-source.png` (1024×1024) — original icon artwork.
- `docguard-mark.png` (512×512) — trimmed checkpoint-bracket mark cropped from the
  source above.
- `../favicon.png` (64×64, one directory up) — the actively used browser-tab icon,
  downscaled from this mark. Kept as the favicon intentionally: a horizontal wordmark
  is illegible at 16×16, so the compact square mark remains the tab icon even though
  it no longer appears in any visible brand lockup.

`docguard-mark.png` and `docguard-source.png` are not referenced by any template or
stylesheet today — they are retained only as the source/derivation chain for
`favicon.png`, not as dead weight. Regenerate the favicon from `docguard-mark.png` if
it is ever redesigned.

## Wordmark family (current brand)

- `docguard-wordmark-source.png` (1024×1024) — original horizontal wordmark artwork.
- `docguard-wordmark.png` (1044×232) — trimmed cobalt-violet derivative for light
  surfaces (footer).
- `docguard-wordmark-white.png` (1044×232) — alpha-preserved white derivative for the
  near-black chrome surfaces (navbar, login, public header), generated by recoloring
  the trimmed wordmark's RGB channels to white while keeping its original alpha mask.

The wordmark image is the sole visible brand lockup across the public landing page,
login page, and authenticated navbar — see `app/web/templates/landing.html`,
`login.html`, and `base.html`.
